## 特点

- 以消息、资料、便签组成一个可调查的手机界面，每项注明来源。
- 原始记录与推断分离，选择证据组合核实判断。
- 地点、地址通知对象、柜码、逐级提示与两种交接结果。
- 次日报平安、可选人物问答与柜台调查；保留夜间原件归属，材料支持不同强度的结论。
- 多种有效证据组合，可不看门店画面完成核对。
- 后续14个决策节点、40个选项承接前两幕：限定参与、原件追还、报告范围、补录来源、授权与本人说明。
- 18个独立结局与三种关系尾声；关系选择不改案情。
- 实际所见先于结论，错误证据回答可以重试；关键错误行为有修正机会。
- 本轮选择可只读回看，也可确认后回到此前场景；后续知情与结局随回退清除。
- 克制的都市悬疑氛围，无血腥或跳脸画面。
- 宽幅工作台与独立阅读视图，材料和答题分开，可自由返回。
- 四幅内置场景插画及放大弹窗，离线HTML直接带图；插画不作为案情证据。
- 结局与关系尾声分别阅读；手记采用目录和单条记录窗口，逐条核对材料、已确认结论与来源。
- 浏览器本地存档，可复制此前候选进度，无运行时模型调用。

## 本地运行

使用 Node.js 24 或更新版本，无第三方运行依赖。

```sh
npm test
npm run build
npm start
```

打开终端输出的本地地址。`npm run release` 为当前版本生成独立 HTML；历史版本不可覆盖，修改后须提升版本号。
