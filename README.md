# 23:17 — 最后一条消息

**一部留在旧手机里的原创互动悬疑短篇。**

林遥把备用机留在你家充电，说下楼买包烟。两个小时后，她发来一句“到北站了”。备用机上同步了发送记录。翻阅会话、照片和便签，找出她留下文件的地方，再决定该把袋子交给谁。

当前版本：**v0.2.0**，可体验迭代版。全部人物与事件均为虚构。

## 开始体验

下载 [v0.2.0 独立 HTML](releases/v0.2.0/23-17.html)，使用现代桌面或手机浏览器打开。无需登录、安装依赖或在线调用模型；进度保存在当前浏览器。右上角箭头可重新开始。[最初的 v0.1.0 样片](releases/v0.1.0/23-17.html) 保留用于比较。

首次游玩建议先读[玩法说明](docs/GAMEPLAY.md)，通关后再看含剧透的[故事内容](docs/STORY.md)。版本变化见[更新日志](CHANGELOG.md)。

## 特点

- 以消息、相册、便签组成一个可调查的手机界面。
- 原始记录与推断分离，选择证据组合核实判断。
- 地点选择、柜码、逐级提示与两种交接结局。
- 克制的都市悬疑氛围，无血腥或跳脸画面。
- 浏览器本地存档，无运行时模型调用。

## 本地运行

使用 Node.js 24 或更新版本，无第三方运行依赖。

```sh
npm test
npm run build
npm start
```

打开终端输出的本地地址。`npm run release` 为当前版本生成独立 HTML；历史版本不可覆盖，修改后须提升版本号。
