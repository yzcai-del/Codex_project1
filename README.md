候选体验入口：[v0.4.0-rc.3 独立HTML](releases/v0.4.0-rc.3/23-17.html)。它仍待真实浏览器验收；当前自动检查覆盖规则和事件处理模拟，不能代替布局、焦点、滚动及移动端验证。

首次游玩建议先读[玩法说明](docs/GAMEPLAY.md)，通关后再看含剧透的[故事内容](docs/STORY.md)。版本变化见[更新日志](CHANGELOG.md)。

## 特点

- 以消息、资料、便签组成一个可调查的手机界面，每项注明来源。
- 原始记录与推断分离，选择证据组合核实判断。
- 地点、地址通知对象、柜码、逐级提示与两种交接结果。
- 次日报平安、可选人物问答与柜台调查；保留夜间原件归属，材料支持不同强度的结论。
- 多种有效证据组合，可不看门店画面完成核对。
- 克制的都市悬疑氛围，无血腥或跳脸画面。
- 浏览器本地存档，无运行时模型调用。

## 本地运行

使用 Node.js 24 或更新版本，无第三方运行依赖。

```sh
npm test
npm run build
npm start
```

打开终端输出的本地地址。`npm run release` 为当前版本生成独立 HTML；历史版本不可覆盖，修改后须提升版本号。
