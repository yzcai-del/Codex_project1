# 玩法说明

## 目标
调查林遥留下的旧手机，判断她实际把文件放在哪里，并找到指定的接收人。

## 操作
1. 在「消息」「相册」「便签」之间切换。
2. 点击可检查的记录，查看原始信息并记录线索。
3. 到「调查」查看已收集内容，选择有证据支持的地点。
4. 从历史会话推导四位柜码，打开储物柜。
5. 选择文件的接收人，读完结局。

## 进度与重玩
浏览器会自动保存进度。存档属于当前设备与浏览器，不同步到网络。右上角圆形箭头可清空进度；结局页可回到最后一次选择。

## 体验提示
一个信息显示的时间，未必就是它被写下的时间。先检查材料，再下判断。无需查找外部知识。

## 当前范围
单个短篇、两个结局。早期版本约 2～5 分钟；阅读速度与探索顺序会影响时长。无实时模型对话。
