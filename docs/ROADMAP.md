# 迭代方向

## 当前候选

v0.7.0-rc.2已接通会面、报告边线、时间补录、原件追还、授权、说明与18个终点。保存和误交路线延续各自来源；关系尾声与案情结局独立。

生产规则穷举覆盖全部设计路径；事件模拟逐条走通结局与选项。真实浏览器布局、键盘焦点、滚动、窄屏及实际交互仍待验收。当前继续保留候选，不覆盖历史发布。

当前候选把现场、选择、材料、核对和手记拆开，增加四幅地点插画与大图查看。桌面采用宽幅阅读，窄屏改为单列；图片离线内置。视图切换和答题草稿与剧情事实分开，支持延续此前候选的进度。

## 后续修订

- 逐场检查知情、材料来源、现实权限与时序，不改变既定事故真相。
- 根据试玩修剪重复解释，改进对白、选择后果和提示。
- 核查长材料与历史记录的窄屏阅读、键盘操作和确认框。
- 真实浏览器验收后再整理稳定版本，不以模拟检查替代。

不扩大为平台，不预先承诺未经实测的游玩时长、玩家或收入数据。

本候选扩展封闭记录调查：获准核对中可分别追问韩维的现场安排、上报时间及孙悦的填写与任务本；追问不要求问满。补录结论同时选择韩的实际封闭上报和孙原接收的指令，区分登记声称、入口照片与独立记录。正式核对路线使用收到的对应来源，不伪造当面访谈。当前追问、证据草稿随回看与刷新保留，提交后在本轮手记记录所选来源；旧版确认过的结论按原规则保留。

候选存档仅按已支持的日志格式恢复，未知格式返回先前可继续的柜台结果，不自动补出来源或结局；旧格式的已确认记录仍按原规则兼容。
