# 迭代方向

## 当前候选

v0.3.0-rc.3加入第二人称叙述、说话人标注与手机/纸面/现场的视觉区分；保留前一候选对第一幕记录来源、授权、地址传递、本人核验、纸质交接与存档恢复的修订。补充交接时知情状态，重写开场和对白。真实浏览器验收尚未完成，候选与已发布版本分开保留。

## 后续推进

- 在保留两条材料流转结果的基础上，推进寄存时间的核对，让不同证据提供不同强度的支持。
- 增加有现实动机的人物问答和调查选择，拒绝提供材料也能保留合理去路。
- 逐段回读人物台词和叙事，减少讲解、总结及重复信息。
- 完成真实浏览器及不同尺寸的验收后，再整理稳定版本。

以完整、可核对的小段推进，不用扩大平台功能替代故事和玩法。不预先承诺真人数据、收入或未经验证的体验指标。
