# 第一幕故事内容

## 简介

林遥参与旧建筑档案整理。她把保留个人号的旧手机放在朋友家充电，带另一个号码的工作机下楼。21:12她说去买烟；23:17，朋友自己的手机收到她个人号发来的到站短信。

玩家已获准查看与这次交接有关的便签、凭证与指定记录，自己的旧会话则由自己保管。界面注明各项来源，没有两部手机自动同步全部记录的设定。

## 已登场人物

- 玩家许岑：林遥的朋友，替她送修过旧手机，也为陈默印过培训材料。
- 林遥：档案整理人员；当夜去向仍待确认。
- 陈默：档案组成员，玩家存有原来的号码，也见过本人。
- 孟雪：青禾洗衣店经营者，说明本店的寄存操作。
- 陌生号码：称替陈老师取材料；称呼本身不能证明委托。
- 司机：只在明确收到取件位置的路线到场，具体身份尚待后续核对。
