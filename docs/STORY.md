# 故事内容

## 不含剧透的介绍
林遥参与一批旧建筑档案的整理。一个普通的晚上，她留下旧手机后失联。玩家通过手机里的零碎记录，追查文件的去向。

## 人物
- **玩家**：林遥的朋友，认识她多年。
- **林遥**：档案整理人员，发现了记录中的问题。
- **陈默**：档案组成员。
- **陌生号码**：主动要求代收文件的人，身份待核实。

<details><summary>展开核心剧情与解谜事实（剧透）</summary>

林遥发现旧建筑原始巡检记录与后续版本不一致。她把原件留在青禾洗衣店的 B17 柜，预留消息作为掩护，约定由陈默接收。

| 记录 | 事实 | 能支持的判断 |
|---|---|---|
| 23:17 的北站消息 | 19:02 已设置发送 | 不能凭到达时间认定当前位置 |
| 北站照片 | 原始拍摄日期为 2024-05-16 | 当晚保存不等于当晚拍摄 |
| 青禾凭证 | 当日 21:06，B17 柜 | 文件留件地点 |
| 历史会话 | 第一声晚安在 23:17 | 柜码 2317 |
| 接收人便签 | 指定陈默，提醒不要回拨陌生号码 | 交接对象 |

两个结局分别呈现原件被指定联系人保全，或被身份不明者截走。林遥最终下落尚未揭示。

</details>
