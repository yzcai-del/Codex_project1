# 故事内容

## 不含剧透的介绍
林遥参与一批旧建筑档案的整理。她把备用机留在朋友家充电，带着常用机下了楼，之后没有回来。玩家从备用机同步的会话、照片和便签追查文件去向。

## 人物
- **玩家**：林遥的朋友，认识她多年。
- **林遥**：档案整理人员，发现了记录中的问题。
- **陈默**：档案组成员。
- **陌生号码**：主动要求代收文件的人，身份待核实。

<details><summary>展开核心剧情与解谜事实（剧透）</summary>

林遥发现旧建筑原始巡检记录与后续版本不一致。她把原件留在青禾洗衣店的 B17 柜，预留消息作为掩护，约定由陈默接收。

| 记录 | 事实 | 能支持的判断 |
|---|---|---|
| 23:17 的北站消息 | 19:02 已设置发送 | 不能凭到达时间认定当前位置 |
| 北站照片 | 原始拍摄日期为 2024-05-16 | 当晚保存不等于当晚拍摄 |
| 青禾凭证 | 当日 21:06，B17 柜 | 文件留件地点 |
| 历史会话 | 第一声晚安在 23:17 | 柜码 2317 |
| 接收人便签 | 指定陈默，提醒不要回拨陌生号码 | 交接对象 |

v0.2.0 中玩家须主动组合两份北站材料，确认它们不能作为实时行程依据；当日凭证才支持去青禾取件。柜码不由弹窗自动给出，需结合便签约定和历史会话推导。

两个结局分别呈现陈默本人签收，或文件袋被身份不明者安排的司机取走。代收结局中原件实际离开玩家手中，避免“发送照片却丢失纸质原件”的因果问题。林遥最终下落尚未揭示。
